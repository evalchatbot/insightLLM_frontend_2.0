# Insight LLM Frontend 2.0

Next.js frontend for chat, OCR flows, and user-facing CSS/PMS study experience.

## Start

```bash
cd insightLLM_frontend_2.0
npm install
npm run dev
```

## Key Stack

- Next.js 14 (App Router)
- React 18 + TypeScript
- Tailwind CSS
- Zustand
